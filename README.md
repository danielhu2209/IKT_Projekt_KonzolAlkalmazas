# IKT_Projekt_KonzolAlkalmazas

## Indítás

1. Nyisd meg a projektet Visual Studióban (Windows).
2. Indítsd el a programot a **Ctrl + F5** billentyűkkel.
3. A főmenüben nyomj **Space**-t a rajzolás megkezdéséhez.

## Vezérlés

**Főmenü:**
- **Fel / le nyíl:** menüpont választása
- **Enter:** kiválasztás
- **Space:** rajzolási mód

**Rajzolási mód:**
- **Nyilak:** kurzor mozgatása
- **Space:** rajzeszköz felemelése / letétele
- **Enter:** egy karakter rajzolása
- **1–5:** rajzkarakter kiválasztása
- **R:** radír be- / kikapcsolása
- **F1–F3:** X nyomda (3×3, 5×5, 7×7)
- **F4–F6:** négyzetkeret nyomda (3×3, 5×5, 7×7)
- **F7–F9:** kereszt nyomda (3×3, 5×5, 7×7)
- **F10–F12:** rombuszkeret nyomda (3×3, 5×5, 7×7)
- **Esc:** vissza a főmenübe

A főmenüben a **Mentés** `.txt` fájlt készít az Asztalra, a **Fájl beolvasás** pedig egy korábbi `.txt` rajzot nyit meg. A **Kilépés** menüpont bezárja a programot.
